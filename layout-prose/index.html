Layout fixture

Prose layout for editorial pages.

A straightforward page shape: hero, markdown body, and an optional single closing call to action.

This fixture exercises the prose marketing template. Editors can keep the body focused on a single narrative and attach one closing CTA when needed.

The closing band title is set via closingTitle; when that field is omitted, the layout falls back to the page headline.
