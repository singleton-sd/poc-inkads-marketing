# InkAds logo system

Exploration canvas (not a marketing page). Recommended direction is **turn 3: unified system**.

## Recommended: Turn 3 — Unified system (1c icon + 1b wordmark)

Icon meaning: framed display holding a content block + two text lines. Reads as “an ad on a screen,” not an empty tile.

### 3a — Icon only

- On black: gold `#ffb300` frame and content block; white + grey text lines.
- On white: mustard `#c89200` frame/block; black + muted grey lines (light-theme rule).

### 3b — Primary horizontal lockup (header / nav)

Icon + wordmark “InkAds” + gold/grey refresh underline + small “by Singleton SD” byline.

### 3c — Stacked lockup

Centered vertical: icon, wordmark, underline, byline. Cover / splash / poster.

### 3d — Wordmark only

“InkAds” + underline. Inline mentions, footers, legal — no icon.

### 3e — Monochrome (for e-paper)

Pure black-on-white, no accent (units are B&W e-paper). Invert for dark device chrome.

### 3f — Small-size check

- 16px favicon: gold frame + gold block only
- 32px app icon: block + one white bar
- 64px nav: full geometry (block + two lines)
- Second text line drops out below ~24px
